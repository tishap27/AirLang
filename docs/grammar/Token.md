**Valid Tokens:**



**Identifiers (ID\_T):**



&nbsp;	-Must start with uppercase letter (A-Z)



&nbsp;	-Can contain letters, numbers, and underscores



&nbsp;	-Examples: Rain, Aircraft1, Flight\_123



**Method Identifiers (MNID\_T):**



&nbsp;	-Must end with ()



&nbsp;	-Can start with any letter



&nbsp;	-Examples: distance(), Rain()



**Keywords (KW\_T):**



&nbsp;	-All uppercase predefined words



&nbsp;	-Examples: IF, THEN, PRINT, MAIN



**String Literals (STR\_T):**



&nbsp;	-Enclosed in double quotes " "



&nbsp;	-Examples: "rain", "B747"



**Integer Literals (INT\_T):**



&nbsp;	-Whole numbers, optional negative sign



&nbsp;	-Examples: -77, 123



**Float Literals (FLOAT\_T):**



&nbsp;	-Decimal numbers with single .



&nbsp;	-Examples: 1.5, -3.14



**Aircraft IDs (AIRCRAFT\_ID\_T):**



&nbsp;	-Format: \[Letter]-\[4 Letters]



&nbsp;	-Examples: C-GHPQ, ZS-EGL



**Flight Numbers (FLIGHT\_ID\_T):**



&nbsp;	-Format: \[2 Letters]\[3 Digits]



&nbsp;	-Examples: AL123, WS456



**Dates (DATE\_T):**



&nbsp;	-Format: 'YYYY-MM-DD' (with single quotes)



&nbsp;	-Examples: '2025-06-24'



**Common Errors:**



Starting identifiers with numbers (7aircraft)



Using lowercase for identifiers (rain)



Missing quotes around strings (clear vs "clear")



Invalid number formats (77abc, 1.5.7)



Incorrect aircraft/flight ID formats



Unmatched parentheses/quotes



Invalid date formats
