Replaced hardcoded block keyword detection with lookup table approach now only requires updating the lookup arrays 
instead of modifying multiple functions with long conditional chains.

- Removed OR chains from isBlockKeyword(), isBlockStart(), isBlockEnd()
- Added BLOCK_START_KEYWORDS[] and BLOCK_END_KEYWORDS[] arrays for clean lookups
- Created BLOCK_MAPPINGS[] table that maps keywords to their instruction opcodes
  (e.g., MAIN keyword -> OP_ENTER_MAIN instruction)
- Added generic isInKeywordArray() helper to eliminate code duplication
- Used extern declaration for keywordTable[] to avoid redeclaring parser data
- Simplified block generation using centralized keyword arrays
